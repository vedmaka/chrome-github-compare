# Privacy policy for GitHub Commit Compare

Effective date: 2026-09-25

GitHub Commit Compare loads on GitHub repository pages to detect in-page navigation. It adds controls only on commit-list pages. On those pages it reads commit hashes and the repository path to create a GitHub comparison URL. This processing happens locally in your browser

The extension does not collect, persist, sell, or share user data with its developer or third parties. When you click Compare, your browser opens a GitHub URL containing the two selected commit hashes. That navigation sends the URL to GitHub under GitHub's own privacy practices

The extension has no analytics, advertising, remote code, account system, or backend. It does not read cookies or authentication tokens

The extension keeps selected commit hashes in memory while the page is open. Closing or refreshing the page clears that state. To stop all processing, remove or disable the extension in Chrome
